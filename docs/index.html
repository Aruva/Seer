SouthSeer tracks EDH league matches, wargame results, seasons, leaderboards, and deck/army rosters — all in one place. Run /lfg to find a game!

Help

If you run into issues receiving Direct Messages from the bot, make sure you have enabled Embeds and link previews in your Settings - Chat, and enable Allow direct messages from server members in your Settings - Privacy & Safety.
